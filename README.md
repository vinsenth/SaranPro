# SaranPro

เว็บแอปปรับภาพให้คม สว่าง และสีสดขึ้น ทำงานในเบราว์เซอร์ทั้งหมด (ไม่อัปโหลดภาพขึ้นเซิร์ฟเวอร์)

🌐 เว็บไซต์: https://vinsenth.github.io/SaranPro/

## วิธี Deploy บน GitHub Pages
1. สร้าง repository ชื่อ `SaranPro` (Public)
2. อัปโหลด `index.html`, `README.md`, `.nojekyll`
3. Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save
